# 主题＋已录制视频

收到主题和视频路径后先检查素材声音与任务范围，再进入下述分支。只有缺少视频本身或存在会改变表达的关键歧义时才询问。有原始讲解的录屏默认保留原声、原速、原片顺序与原画幅，完整展示源画面；不要为套用 16:9 模板裁掉界面或人物。完整发布交付的封面仍为 4:3、3:4、16:9，附标题、描述和话题。

沿用 [共用流程](../workflow.md)，先审片并理解主题；有讲解时转写，无声素材按实际画面建立内容记录。采用 HTML 前审时，确认当前预览后制作海报和发布文案。已有用户认可的本期海报可直接复用，交付前核对与成片一致。

## 先区分原声成片与录屏素材

- **有原始讲解：默认原声精剪。** 使用下文的精剪、EDL 与接缝检查，不因若干秒没有说话就把整片当成无声素材重新配音。
- **无声录屏：可以当素材制作。** 没有原始讲解、仅有环境声／点击声的素材也可按此分支处理。根据真实操作与主题写脚本、选取视频片段、安排讲解顺序，需要讲解处使用已授权音色配音，再加普通字幕和必要关键词气泡；无需为了遵守原声精剪规则而额外索取改编许可。演示缺少讲解时可适当补充 TTS，使用当前视频中已授权的本人音色，保留连续动作与有用的系统声；整片无可用人声时复用已授权参考，不冒称从无声视频提取音色。用户明确要求保持无声、原顺序或完整展示时照其要求执行。
- **混合素材：分段标明用途。** 保留已有讲解的部分；独立无声素材可承载新旁白，不把讲解中的呼吸、等待与无声操作误判为可任意改编区间。

无声素材走[脚本](../stages/script.md)、[分镜](../stages/storyboard.md)、[声音](../stages/voice.md)和[动态信息层](remotion.md)的制作流程。允许选段、按讲解组织镜头和必要的细节展示，但演示操作仍保留“动作 → 反馈 → 结果”的连续视频，不用截图拼装或假点击冒充过程。需要配音不等于采用漫画风；字幕默认清晰简洁，系列包装须来自当次选择。

演示段缺少讲解或承接时，可适当补充目标、动作或结果说明，使用当前录屏中已授权的清晰人声作固定参考；这属于本路线允许的局部补充，不需逐句另问。优先保留已有原声，先恢复误剪声音，再处理原片确实缺少讲解的部分。补充文案服从真实画面与可用时长，不为了等 TTS 冻结、拆散或倍速操作。最终混音需检查接点音量、音色和听感，字幕重新对齐；正常呼吸与短暂停顿无需逐秒填满。用户明确要求静默的区间才登记静音豁免，不能以“演示”名义忽略应补的讲解。

下文 `prepare_recording.py` 是原声音画同步剪辑入口，需要源音轨；无音轨素材使用所选视频合成路线并接入最终配音，不把空音轨伪称为原声。无声素材没有可提取的本人音色，复用已授权参考，缺少时再确认声音来源。

## 默认精剪边界

本节及下文原声母版流程适用于有原始讲解的录屏；无声素材按上一节制作。

- **连续原片是主体。** 只删除不影响意思与操作的口头禅、重复试说、口误和无信息等待。保留原本的讲述顺序、自然停顿与原声收尾；不按新文案拆成截图场景。抽帧仅用于审片与定位，不能拿来替代成片中的连续录屏；不冻结画面等待新旁白，不模拟鼠标动作补造过程。
- **动作比删词优先。** 标出关键的“入口／点击 → 状态变化 → 结果”，例如打开文件、保存、回放、查看报告。口头禅与这些动作重叠时保留该段，不因追求删尽“然后”而删掉操作因果。无声时仍有输入、加载反馈或结果阅读就不是自动可删的空白；长等待只缩短无变化的中段，保留开始、完成及理解所需停留。
- **信息层保持轻量。** 按实际说话加清晰简洁的普通字幕，样式与语言沿用本期明确选择，不擅自套用漫画字体、描边、跳字或积木包装；关键词出现时叠简短气泡，讲完收起，避开鼠标、输入框、报告与人头。气泡不替代界面，不为每句字幕切页、切截图或插整屏卡片。默认保留原录屏内的人头；“新增角色不说话时隐藏”不能解释为抹掉原片人物。
- **补充制作按明确要求。** 默认不重配整片、不添加问候或三连片尾、不重排片段、不倍速；演示确实缺少讲解时允许按上一节用当前视频音色适当补充。保留现有声音不等于重新克隆同音色配整片。用户已授权补录、重配音或新片尾时，只处理所需范围并核对与原片的衔接。脱敏只覆盖本期指定对象及其实际出现区，不扩大遮挡。
- **接缝先回到源片修。** 逐个播放剪切点前后完整语句和动作。断字、突然静音或页面瞬移时，先恢复被误删的声画、扩大保留区间或撤销该次切除；不靠补一句 TTS、冻结截图或花哨转场掩盖。确有爆音可做短音频淡化，但不能吞字、移动声画或交叉混合不同操作状态。

## 从原片到成片

1. 检查视频时长、尺寸、旋转、帧率、音轨及可读性。抽帧看人物位置、手势和已有字幕；转写全部原声并取得词时间戳。ASR 使用已授权服务或本机工具，外部服务不可用时如实说明缺口，不能靠字数编造对齐。
2. 转写用于定位冗余词与理解原意，不用于重写故事。逐项列出源视频保留区间、删除原因及必须保留的动作，保留否定、条件、限定、自然呼吸与开头结尾。只有经声画复核可安全删除的内容才写入切除区间。
3. 将剪辑决策写入 EDL。先做音画一起剪的母版，再规划最终时间轴。`scripts/prepare_recording.py` 默认按原顺序、原速拼接单源片段；重排或变速仅用于显式选择的 `editorial` 模式。多个源视频先统一技术参数并整理母版、保留各源映射；不要把不同源文件的时间误当成同一源时间。
4. 对剪辑母版的最终 WAV 重新对齐。源时间戳也可通过剪辑映射转换，但删节边界的词需人工核对，重排后需重新排序。母版锁定后字幕、强调词、卡片都使用最终时间；变更剪辑就重新对齐。
5. 在最终时间轴区分真人口播与系统播放，保留实际点击和完整反馈；不能用较晚的系统声音起点代替点击帧。原片已有引入就保留，没有引入不强制补录。用户口播加中英双语；系统已经有字幕的播放窗口只保留原字幕。关键词用轻量气泡叠在同一连续母版上，复看控件与字幕安全区；不因使用气泡切换到整片漫画重编路线。
6. 默认保留原片自然结尾。明确要求新互动片尾时，先在正文说完收束句，再转入积木互动；模板动作随实际词时间逐项出现，最后一声结束后留停稳。获授权补录时使用指定音色参考。使用下方入口导出并检查实际 MP4。
7. 按 [海报节点](../stages/poster.md) 完成三种独立构图并检查尺寸，核对海报与最终剪辑一致。交付成片、独立音轨、SRT、三种海报和发布文案。

## EDL 与执行

路径相对 JSON 所在目录。此处秒数仅示范结构，实际值来自原片；`segments` 顺序即成片顺序。每段 `reason` 记录人工判断；工具不会自动识别语义口误。

`edit_mode` 默认 `source_preserving`，拒绝倒序、重叠区间和非 1 倍速。只有任务明确要求重排／变速时才设 `editorial`，并在 `user_request` 记录实际要求；此模式仍检查区间、速度边界与口头禅切除重叠。程序不能判断某次切除是否丢掉真实操作，须按下方连续性检查复核。

必须连续展示的操作写入 `continuous_ranges:[{in,out,reason}]`（源时间），覆盖入口动作到结果。`prepare_recording.py` 在生成母版前强制检查这些区间：不能漏帧段、插入其他片段、重复、倒序或变速，即使 `editorial` 模式也不能破坏它们；源时间按项目帧取整。输出 `edit-map.json` 记录对应的成片时间供字幕与演示窗口使用。该规则需要制作时如实标出关键操作，不能自动识别漏标的动作，也不能保证绕过本入口的自编工程正确。

```json
{
  "source": "source.mp4",
  "fps": 30,
  "edit_mode": "source_preserving",
  "continuous_ranges": [{"in": 12, "out": 17, "reason": "打开结果并完成展示，保留连续操作"}],
  "filler_cuts": [{"in": 8.7, "out": 9.1, "text": "然后"}],
  "segments": [
    {"in": 1.2, "out": 8.6, "speed": 1, "reason": "保留完整开场"},
    {"in": 10.1, "out": 19.5, "speed": 1, "reason": "去掉重录，保留有效说明"}
  ]
}
```

```sh
python "$SKILL_DIR/scripts/prepare_recording.py" work/task/edit.json --output-dir work/task/edit-v1
```

输出 `master.mov`（H.264＋PCM）、`narration.wav`、`edit-map.json`。脚本默认拒绝覆盖，重做使用新目录。源时间四舍五入到项目帧，保留映射；编码和保调变速会有帧／采样量化，最终对齐使用实际 WAV。音量处理在拼接后统一执行；默认 -16 LUFS，仍需检查峰值和听感。

人工确认的冗余「然后」「其实」「可能」写入可选的 `filler_cuts`，保留区间不能与这些切除区间重叠。保留表达先后、假设或限定的同形词。剪辑后从实际声音核对残留口头语、被截断的字和接缝。工具分别按帧和累计样本对齐，验证解码帧数再交付母版。

`master.mov` 在合成中静音播放，使用同次处理得到的 `narration.wav`，声画共享同一剪辑映射；不要遗漏原片的系统声。仅在用户要求补录时改用已核对的最终混音。字幕、气泡在连续母版上合成，不能把母版换成抽帧序列。当前 `render-recorded-edit` 负责字幕与可选片尾，气泡需复用[动态信息层](remotion.md)的实际组件叠在母版上，不虚构该命令支持的气泡字段。

## 连续性检查

HTML 前审与最终 MP4 使用同一母版、音轨及叠加时间轴，沿用公共播放器布局。逐个复看切点前后完整语句与动作，另连续播放全片：

- 原片顺序、原速、画幅与人物保留；任一操作段可追溯到 EDL 的源区间，画面随原视频播放而非静态图轮换。
- 打开、输入、保存、运行与查看结果的关键动作仍能看见；没有省略点击直接出现新页面，没有用假光标或转场补造因果。
- 没有切断字音、突然掉声、重复语句或新增音色接缝；区分有效无声操作和编辑制造的空洞。
- 字幕与关键词跟随最终原声，提示不盖住操作对象；文字可读性通过保留分辨率与合理叠加解决，不擅自换成截图放大页。

检查失败先恢复或调整源区间，再对齐字幕。程序通过、抽帧好看都不能代替连续播放与听审；未完成的检查如实记录。

## 双语成片与有声片尾

默认原声精剪省略 `outro`，正文母版与全片同长，`voice` 为 `original`；系统播放没有原有引入时可省略 `intro`。有明确新片尾要求时，正文母版包含收束句，结束帧就是转场起点；最终 WAV 才包含相应补录、片尾口播及末尾停留。计划中的秒数采用**最终成片时间**。

| 字段 | 填写 |
| --- | --- |
| `schema_version`、`fps`、`duration` | 版本 1，项目帧率和总时长，时长精确到帧 |
| `captions` | 每条填写 `start`、`end`、`text`、`en`，中文一行、英文一行，长句按意群拆分 |
| `keywords`、`keywordsEn` | 可选双语关键词，字幕可以逐条覆盖 |
| `playback` | 每次系统播放的 `start`、`end`、`embedded_captions`；`intro:{start,end}` 按实际引入填写，没有引入可省略；局部补 TTS 不强制所有演示新增引入。无系统播放时填 `[]` |
| `outro.template` | `community-outro-v1`，文案和动作取自 [outro.json](../../assets/production/outro.json) |
| `outro.closing` | 收束句 `start`、`end`，可用 `text` 核对指定台词 |
| `outro.transition` | 帧边界上的 `start`、`end`、真实 GL 效果 `name` 和可选 `params`，积木片尾可用 `gl:GridFlip` |
| `outro.narration`、`outro.actions` | 片尾口播 `start/end`，依模板顺序提供实际词起点 `[{anchor,at}]`。末句后至少留 0.25 秒 |
| `voice` | 全部原声用 `{mode:"original"}` 或省略。补录用 `mode:"current_recording"`，提供 `reference_audio`、`excerpt:{source,start,end}`、`generation_reports`。明确要求其他授权音色时用 `authorized_alternative` 并记录 `user_request` |

路径相对计划文件。补录样本可以由原录屏或同一录屏剪辑后的原声音轨抽取。按单人连续口播选段，附真实参考转写，调用 [本地配音](local-tts.md)。样本用单声道 PCM16，检查器复抽比对采样数据，并核对合成报告的参考哈希。

```sh
python scripts/production.py check-recorded-edit work/task/timeline.json --plan-only
python scripts/production.py render-recorded-edit work/task/timeline.json \
  --body work/task/body.mov --audio work/task/final-mix.wav \
  --output outputs/task/video.mp4 --srt outputs/task/captions.srt
python scripts/production.py check-recorded-edit work/task/timeline.json \
  --video outputs/task/video.mp4 --srt outputs/task/captions.srt
```

需要本地字体时用 `--font-name/--font-file`。导出入口复用积木和双语字幕组件，独立解码录屏与 Remotion 后拼接，防止音轨长度掩盖视频在片尾前中断。检查实际 MP4 帧数、时间戳、音轨、有声区间和配套字幕后再发布输出文件。还需实际检查播放按钮、积木落位、字幕避让和新旧音色的衔接，区间内有声和自动转写不能代替听感验收。
