# 小龙系列的明亮玻璃科技风

小龙工具介绍片的可选视觉预设；其他品牌、原声录屏或当次参考可独立选择。Bot 造型见 [Bot 样式](bots.md)，小龙与口型见 [角色](character.md)，信息布局见 [画面](../stages/visuals.md)。

## 空间与材质

以明亮冰白、浅冰蓝为大面积背景，低饱和蓝紫光场建立纵深。大弧面、玻璃环与轻透视底座形成舞台，地面细网格仅在近看时可见。主体、界面与字幕保持清楚的前后层次，光向和阴影一致。

玻璃卡片用半透明浅底、细亮边、柔和内高光与宽软投影；透视、模糊和反光以不影响阅读为限。标题用深蓝色，角色与 Bot 保留原生颜色。真实产品界面可保留其深色主题，置入明亮玻璃框中，不为统一配色篡改产品截图。

## 可复用色值起点

| 用途 | 起始值 |
|---|---|
| 背景光场 | `#FFFFFF → #EDF7FF → #D9EAF8` |
| 主文字 | `#183A56` |
| 次文字 | `#5E7D98` |
| 玻璃表面 | `#FFFFFFC9 → #FFFFFF55 → #BDD8EF66` |
| 辅助色 | 青蓝 `#287FA3`、柔紫 `#8670B9`、珊瑚 `#BC657B`、绿 `#6E963D` |
| 字幕关键词 | 暖金 `#FFE18C`，完整字幕规格见 [字幕](../stages/captions.md#中文口播的显示标点与关键词) |

这是本风格的设计色值，独立于随包基础 `style.json.palette`；Bot 的饱和色另由其样式模块管理。背景、平台、卡片、连线和标签已实现于 [glass.jsx](../../assets/remotion/src/effects/glass.jsx)，通过 `modules.background=glass` 和相应 `effects` 选择，见 [动画模块接口](../tools/animation-modules.md)。

## 构图与复核

- 保留一个主焦点：真实界面、正在变化的任务对象或小龙。配角可在边缘探头、停靠；进入主体附近时避开按钮、关键结果与字幕。
- 小龙有中心开场、近景与参与操作的中景，不把全片做成左右站位轮换。尺寸随阅读任务调整，跨场保持身份和合理运动方向。
- 解释产品时放大真实界面，并按当前口播聚焦相应区域；玻璃装饰不替代功能证据。模拟操作明确标示意。
- 在手机尺寸检查标题、任务标签、产品信息与字幕。尤其检查浅底上白色五官、玻璃卡片边界、平台按钮遮挡及片尾行动区域。

视频风格与海报分开维护；用户允许沿用的海报继续复用，换成玻璃视频背景不自动触发海报重生成。
