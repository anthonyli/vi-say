# 视频可选色板

这是一组**可选颜色的范围**，不是主色／成功／警告等功能配色，也没有风险等级映射。最初复制的 key 不属于设计要求。根据内容、构图和可读性自由搭配，无需用齐所有颜色，也不固定哪一种必须占主导。

## 可以使用的颜色

| 颜色 | 色值 |
|---|---|
| 蓝色 | `#2E90FA` |
| 绿色 | `#07C790` |
| 黄色 | `#F7B035` |
| 橙色 | `#F47345` |
| 浅蓝色 | `#81A5E9` |
| 黑色 | `#000000` |
| 白色 | `#FFFFFF` |

随包基础色板的配置来源是 `assets/production/style.json → palette`。其中 `blue/green/yellow/orange/lightBlue/black/white` 只是便于引用的颜色名称，不赋予用途含义。JS 从 `assets/production/colors.mjs` 导入 `PALETTE` 或 `ALLOWED_COLORS`；Python 读取同一份 JSON。

当次已选择的品牌与风格优先。小龙系列的 [明亮玻璃风](glass.md) 与 [Bot 样式](bots.md) 各自维护其色值；选择模块预设后调用对应组件，基础色板继续服务原风格。

## 使用规则

- 使用随包基础色板时，视频背景、文字、卡片、图形和装饰从上述范围选色；已选择其他品牌或风格时，按相应模块的色板统一使用。
- 颜色的用途、组合与占比按当期内容决定。绿色不强制代表成功，橙色不强制代表危险，也不自动生成任何风险等级配色。
- 允许使用这些颜色的透明度叠加形成浅底或阴影，不引入额外基础色相。
- 正文以清晰可读为先；彩底上的文字需检查对比度，不默认都配白字。
- 实录、截图和角色保留原生素材颜色，不篡改产品界面或强制重染角色。
- **海报有单独确定的黄色系列风格**，遵循 [poster.md](../stages/poster.md) 和 `style.json → poster.palette`，与这里的视频色板独立。

## 开源用户如何调整

1. 修改 `style.json.palette` 的颜色值即可替换默认色板，名称仍只用于引用。
2. 不需要配置状态、功能或风险映射；由当期内容决定怎么用色。
3. 只改海报时，编辑 `poster.palette`；不改视频色板。
4. 修改后生成短样片，检查文字对比、背景层次和素材协调性。

以上是随包提供的默认色板，可由使用者替换成自己的品牌颜色，不把作者的偏好写成所有项目不可更改的规则。
