# 城市介绍视频

用户给出城市名，或要求城市宣传片、人文旅行片、城市历史片时使用本路线。让观众通过真实场景理解城市的性格，感到它与自己的生活有关。内容按情绪和因果推进，每处景物都承担叙事作用。

本路线由 Agent 完成资料检索、选题、脚本和素材组织，再调用已有制作工具。城市名是任务入口；渲染器需要实际音轨、画面和时间轴。执行能力与依赖以当前工具环境为准。

## 只有城市名时怎样开始

沿用当前会话中已经确定的用途、参考和制作偏好。其余采用下表的起点，记录在本期项目约定里并简短告知用户，直接开始取材。仅在同名地点无法确定、必要素材不可取得或授权范围无法判断时询问所需信息。

| 项目 | 默认起点 |
|---|---|
| 受众与视角 | 普通观众，由城市讲述者带路，用可感知的生活细节解释背景 |
| 主题 | 先查资料，再提炼一个有证据支撑的城市性格与核心问题 |
| 篇幅 | 约 5–8 分钟，以信息密度和实际口播时长调整；用户要求深入历史时可延长 |
| 内容 | 文化、美食、历史人物与城市发展相互衔接，并落到当代生活 |
| 声音 | 当前项目已有授权的固定音色，普通话正文；缺少可用音色时明确提出依赖并继续取材、写稿和分镜 |
| 节奏 | 语句紧凑自然，事实段清楚，情绪收束留停顿；加快要求按声音节点实际处理和复核 |
| 画幅与画面 | 16:9，以城市实景、生活动作、必要的历史图解和 AI 示意组织镜头 |
| 交付 | 有声视频、独立音轨、口播稿、字幕、三比例海报、发布文案及必要来源说明 |

亲子共创、儿童友好、特定城区、方言首尾、战争、民族互助或工业专题按用户要求与当地资料展开。只有确属当期任务，才写学校活动、家庭参与等背景。城市片使用自己的讲述者、片头与收束方式。

## 查证与取材

先浏览当地地方志、档案馆、博物馆、纪念馆、政府文化机构、正式出版资料及可靠报道。搜索摘要用于找线索，重要事实打开原文核对。城市发展数据和开放状况记录口径与资料日期。

本期 `work/<项目>/` 保存精简的事实表，每行记录主张、时间地点、人物关系、原始来源及链接、对应原文位置、核实状态、拟用段落。所有进入稿件的历史事件、人名、年份、引文、数字与“第一／唯一”等说法都须能回查。争议或矛盾资料保留限定，无法核实的细节删去或改为可证明的表述。

- 文化从当地语言、建筑、文学、手艺或生活习惯中选取，解释它今天怎样被人使用。
- 美食落到真实食物、做法、吃法、时令与生活场景。起源传说注明传说，口感描述以可核实材料为依据。
- 历史人物说明其在当地的具体行动及影响，核对出生、居住、任职或事件发生地的区别。
- 战争与救助讲清时间、参与者、行动、处境和结果。核对人数与称谓，避免用虚构对白、私人心理或合成人物填补史料。
- 国内不同民族互助选取有出处的完整事件，讲清谁在何时如何帮助谁、造成什么影响。区分国内民族、国籍和宗教身份。
- 人口迁移、青年建设与工业发展须交代当时背景和具体贡献，并依据材料呈现生活代价与复杂经历。
- 城市发展用一个地点或行业的前后变化解释交通、生产、住房、公共空间怎样影响普通人。核实历史地名与现今行政区划。

按证据和主题选择详略。重要故事用“处境—行动—影响—今天的联系”讲完整，其他材料可作为过渡或背景。整片需让观众理解城市，而不是只认识若干地标。

## 从事实写成有推进的故事

先用一句话写出本片想回答的问题，再用一句话确定城市性格。性格可以包含张力，例如繁忙中的体贴、迁徙中的归属。每个形容词至少落到一个当地独有的事实或可见细节。

开头约 3–5 秒提出具体问题、唤起共同记忆或打破既有印象，随即给出能兑现它的场景。选一个真实的行走动作、空间关系或日常物件串联全片，转段交代为什么从此处走向下一处。

可按以下情绪推进组织，章节数量和次序服从资料。

| 推进 | 内容作用 | 观众应得到什么 |
|---|---|---|
| 好奇 | 从可感知的小问题进入城市 | 愿意跟着走 |
| 亲近 | 街道、饮食、语言与日常动作 | 感到生活的质地 |
| 理解 | 历史人物、文化形成与城市变迁 | 明白眼前生活的来处 |
| 触动 | 有事实依据的坚守、救助或互相支持 | 看见城市性格如何体现在行动里 |
| 回到今天 | 生产、公共空间与普通人的当代生活 | 感到过去与自己仍有关联 |
| 回味 | 回扣开场的物件、问题或动作，邀请观众亲自经历 | 留下一幅具体画面或一个可参与的行动 |

每段先给事实或动作，再写感受。诗词、历史和影视记忆可作入口，需核实出处及地方关联；借字发挥写成文学联想，地名来历按史料解释。宏观段落之后回到一口食物、一条街或一个人的行动，控制抽象抒情的连续长度。

写完逐段做城市辨识度检查。替换城市名后仍普遍成立的句子，补入本地细节或删去。检查各段是否增加信息、上一段怎样引出下一段、结尾是否回应开头。篇幅不足时补真实背景和因果，篇幅过长时删重复赞美与同义景点。

儿童参与适用于已确定的亲子主题。安排观察、提问、识字、尝味或参与公共生活等关键动作，由讲述者解释复杂历史；脚本中的设想动作标为待拍，真实参与情况据实记录。

## 配音与方言

按[声音节点](../stages/voice.md)选定本期授权参考，完整写好开头、正文和结尾再合成。音色身份、表达风格与语言分别记录。通用技能只保存方法，具体参考文件、授权和私有配置留在制作项目。

要求方言首尾时，先写适合本片的新开场和收束句，核实地方表达与读法，再使用具备相应能力的后端生成。参考录音作为音色或发音依据；只有明确要求引用原声时才剪入原录音。分别听查两段方言与普通话正文的交接，字幕给出易读的意思，不能把普通话合成结果登记成方言通过。

先短测地名、人名、多音字、数字和方言，再生成正文与结尾。长篇固定音色使用现有分段锚定能力并检查接缝。用户希望更快时先压缩赘句、修复异常停顿，必要变速沿用[音频修复](../tools/audio-repair.md)与时间映射，保留自然音高。最终音轨锁定后重新对齐字幕和镜头，并检查输出视频内的音轨。

## 画面与剪辑

分镜按“口播依据—画面承担的信息—素材来源—动作—转场—字幕”记录在本期文件。真实照片、可用视频、地图、档案及生成画面按需要组合。AI 画面可以表现空间、气氛和历史场景示意，具体事件必须真实，复原画面明确标为 AI 示意；核对服装、建筑、交通工具和地理关系，避免把生成图当作历史照片。

使用现有[Remotion 与 FFmpeg](../tools/remotion.md)或适合的既有渲染入口。先按真实镜头编排连续画面和声音，再添加字幕与必要的信息层；复杂地图或空间表达按[扩展说明](../extensions.md)实现并实渲。镜头参数遵守所选接口，叙事提纲不能直接当作渲染 JSON。

优先以动作、方向、形状、声音或主题关系完成转场，在章节转折适量增加视觉效果。历史苦难段保持克制，日常与发展段可提高节奏。环境声和音乐服从口播与语义，核对可用权限。先实渲含实际字幕切换和跨场接点的短片，再扩展全片。

字幕从最终音轨对齐，采用稳定图层和连续的有效帧区间。逐帧核对相邻字幕边界，消除取整造成的单帧空白、重复挂载导致的闪动和整层淡入淡出；真实语音停顿保留合理无字幕区间。正文用易读的短行，人名、年份和地名核对显示与读音。

外来素材记录来源、用途和可用权限，检查全片水印与平台标识。需要处理标识时核实素材使用范围，优先取得可用的干净源文件；无法取得时更换合适素材或使用明确示意的生成画面。

## 前审、海报与完整交付

遵从[共用前审设置](../workflow.md#html-前审)，复用公共播放器。只给城市名时继续完成资料、稿件、声音和有声预览，按生效设置进入成片阶段。将实际检查与尚未确认的内容如实记录。

从[交付模板](../tools/delivery-check.md)登记完整范围，调整为本片实际片头和片尾的文本要求。确认前审并进入正式交付时，调用 `production.py promote-delivery`，再按正式清单补齐成片与配套文件。已有正式清单的局部修订使用 `revise-delivery`。

三比例海报按[海报节点](../stages/poster.md)制作，以同一标题、主题主体和视觉语言分别构图。用户认可某一比例并要求其他比例一致时，把已认可原图作为真实输入参考，保留主体身份、色彩与文字，对每个比例重新安排位置。既有合适图片按哈希复用，实际提示词和输入图角色保存在当期项目。

发布文案用独立 `发布文案.txt`，写清本片视角、值得关注的真实细节和相关话题。亲子或学校任务按已知事实说明共同制作过程，不虚构实地到访、采访或孩子的感言。

最终按[交付节点](../stages/delivery.md)检查史实与来源、口播完整性、方言及人名、最终音轨、字幕切换、主要跨场接点、画面标识与海报一致性，执行 `production.py check-delivery`。回复同时提供视频与配套文件入口，并说明实际未完成的验证。

本路线的公共内容保持为制作方法和工具路由。每座城市的台词、事实表、人物与事件、生成提示词、参考片、参考海报和音色配置留在当期项目。可用“用 vi-say 为我做一条关于 {城市名} 的城市介绍视频”启动新任务，花括号内容由用户给出的地点替换。
