# 海报制作规范

随包默认采用 **参考原图、整张图像生成的亮黄漫画海报**。它独立于[视频色系](../styles/colors.md)，可由其他使用者替换成自己的品牌。本文件是海报风格、制作方法与变更记录的统一入口。

## 在流程中的位置

海报放在理解素材、提炼主题之后，完整口播、配音和动画制作之前。先生成并展示一张代表海报，让用户尽早看出本期主题、核心收益、内容重点与视觉方向。用户明确要求先确认时等待反馈，其他任务按已有要求继续；生成次数与修改遵循下文的停止条件。

展示代表海报后，按任务要求独立排版其他比例；已有本期对应比例直接复用。成片交付前核对标题、主题素材与最终内容一致；发现不一致时记录待修改项，不重新启动海报生成流程，也不把不一致的海报标为通过。海报不替代运动、发音和真实操作的后续检查。共用阶段见 [workflow.md](../workflow.md)。

用户已明确允许沿用的海报，修改开场、声音、字幕、Bot 或视频背景时继续保留原图；复核文件哈希，只有当次明确要求改海报才按对应比例修订。

成片完成后，用户另行要求用于自媒体分享制作经历的海报，属于新的传播用途；先按 [发布文案](publishing-copy.md) 确定作品分享钩子，复用已有成片素材，独立记录该用途的生成次数。不得把交付时反复检查旧海报假称为新用途。产品销售封面与作者作品分享封面不必使用同一个标题或 CTA。

原海报的制作记录使用 **imagegen 生成整张海报，包括文字**，没有指定可还原的字体文件。因此不能把字形认定为某款字体，也不能声称换成一款粗黑体就能复刻。脚本草稿使用当前环境选择的字体；加粗、描边或模糊边角仍不能保证复现原图的圆润展示字设计。

## 默认视觉

- **亮黄色底**，保持明亮、饱满、有活力；不默认切成蓝底、奶油底或浅绿底。
- **占主导的圆润展示标题**，字面厚实、转角与端头圆钝、字腔舒展，保留参考图的活泼字形；厚白贴纸描边与浅暖色短投影。橙红色只强调少量关键词。字号同时服从四周边距、自然字宽和主体间隔，缩成手机缩略图仍要清楚。
- **立体主题素材**放在标题下方或侧面，使用白色贴纸轮廓。角色、工具、界面或物件应与当期内容相关；不把任何主题都改成同一张巨大角色照。
- **底部紫色胶囊标签**，白色粗字，写系列名、明确收益或相关工具。禁止添加未经核实的夸张效果。
- 少量感叹线、星芒与气泡提供活力；感叹线必须是抗锯齿的圆头胶囊形，倾斜后也不能露出方头。描边转角圆润，标题采用浅暖色贴纸投影，避免厚重的硬黑错位底边；不要用装饰遮住标题或产品证据。
- 小龙是默认系列角色，不是不可替换的品牌要求。可替换、缩小或按主题使用其他已授权素材。

默认色值在 `assets/production/style.json` 的 `poster.palette`：亮黄 `#FFE600`、重点橙红 `#FF4B0A`、标签紫 `#6200EA`、黑 `#000000`、白 `#FFFFFF`。这是海报专用色板；换品牌改这里即可。角色、真实截图的原生色彩保留。

## 文案与版式

1. 提炼一个真实收益，标题通常 2–3 行，每行尽量短；品牌名可独立一行。
2. 让主标题占据最大的视觉权重；可用一处橙红重点词，避免所有文字都强调。
3. 主题素材和标题共同解释这期内容，不拿无关玩偶或假界面填空。
4. 底部只留一个短标签，不塞长网址、多个 CTA 或制作说明。
5. 4:3、3:4、16:9 各自排版，不裁掉文字、不直接拉伸一张海报。

**内容饱满与舒适留白同时成立。** 标题、主题素材和底标分布均衡，正文区域没有明显闲置的大洞，四周保留可见且协调的边距。没有既定版式时，可从画布宽高各约 5%–7% 的外边距起排，再按参考图和用户要求调整；边距与元素间隔不能为凑满画面而被吃掉。先安排内框、行位置和主体位置，再微调字号与比例。每行按字形自然宽度排布，不要求三行等宽、不横向拉宽字形；小龙是辅助主体，不为填空随意放大。少量相关点缀承担节奏，保留边缘留白。参考竖版图时沿用字形、材质和装饰语言，横版另做构图。

16:9 默认采用左侧主标题、右侧与标题比例协调的主题素材，底标在下方平衡构图；可按素材左右互换。标题保持 2–3 行，标题与素材横向铺开，避免所有内容挤在中间、左右出现大块空白黄色竖带；素材和白描边仍须与标题分开，不以遮字换饱满。这些要求在首次生成的提示词中写清，不在出图后靠反复重生成碰运气。

| 比例 | 默认尺寸 | 构图 |
|---|---|---|
| 3:4 | 1080×1440 | 上部大标题，下部主题素材，底部标签 |
| 4:3 | 1440×1080 | 左侧标题，右侧主题素材，底部标签 |
| 16:9 | 1920×1080 | 左侧主标题、右侧主题素材、下方标签；沿宽度展开，同时保留四周边距 |

## 字形基准与增量修改

首次制作确定本期字形与材质参考：优先用用户明确指定或已认可的原图，否则以 Handy 示例为中文字形主基准，原海报辅助材质和装饰；使用多张参考时明确各自职责，避免等权混合不同字形。每次图像调用都实际提供这张风格基准，并在提示词中写明它负责字形、白描边、浅暖投影和装饰语言。小龙母版负责角色身份，当次编辑底图负责现有版式与已达成状态；用户指定某张本期输出作为点缀等专项参考时，另外标明职责。这些输入不自动取代固定字形主基准。跨比例继承同一字形和点缀语言，独立调整构图。

修改前从对话和本期记录列出保留项、此次改动和实际输入图片角色。累计保留用户已提出、且未被本轮明确修改或撤销的要求。仅把用户指定项作为本轮改动，不把上一版的偏差继续升级为风格基准，也不借局部修改重排整张图。保留项描述当前已达成的状态；前轮已经完成的缩小比例不在后轮再次累乘执行。

检查时将当前图与固定风格基准直接对照，分别看中文字形的转角/端头/字腔、自然字宽、白描边、浅投影、标题层级、主体比例、四周留白和少量点缀。仅在提示词写“rounded”或给方黑体加描边，不构成字形通过；整图编辑也不能宣称文字像素锁定。若本轮发生未要求的字形或版式漂移，标为待修改并按停止条件结束，不自动追加出图。

## 默认制作流程

1. 先查看固定字形/材质参考及当期版式目标，核实各输入图真实尺寸，确定准确标题、重点词、底标、保留项和此次改动。文件名中的比例标签不替代实际尺寸；不同画幅的风格图只提供其指定的风格，不继承画幅。每次实际提供风格基准；使用小龙时另提供角色母版 `assets/production/dragon.png`。在本期记录中分别标明图片角色和路径。
2. 使用图像生成工具，把参考图作为视觉参考，**连同文字一起生成完整海报**。不要只生成角色后默认改用脚本排大标题。背景不透明。
3. 每个所需比例默认只调用一次生成，检查并展示结果后结束该比例。逐字核对文案，并与固定参考对照圆润字形、白描边、浅投影、边距、主体比例、点缀语言和缩略图可读性；有问题如实标为待修改，不自行再次出图，不能把生成成功记为用户认可。
4. 脚本可辅助尺寸、比例、文件完整性检查与等比缩放；不得拉伸、裁掉标题，或为了凑精确像素悄悄替换成另一套排字。记录生成原图与导出图的实际尺寸。比例仅有轻微偏差时可等比置入目标画布并用背景补边，例如 1920×1072 上下各补 4 像素至 1920×1080，不为这类像素差重新生成；比例明显不符时标明问题，不把错误比例记为通过。
5. 在当前项目保存 `poster-record.md`：日期、固定风格基准、当次版式目标、每张实际输入图的角色、真实尺寸与版本、累计保留项、此次改动、完整提示词、工具与可取得的模型信息、逐比例输出路径和实际尺寸、实际调用次数、检查结果、用户反馈及修订依据。只写确实可知的信息。

## 生成次数与停止条件

- **默认每个所需比例一次调用。** 三比例交付通常共三次，代表海报计入其中；不额外生成“备用版”“优化版”或多张候选。
- **后续节点复用已有结果。** 重新检查、补齐交付、恢复任务或再次读取本规范，都不重置次数。调用前先查本期 `poster-record.md` 和已有文件，只生成缺失且未调用过的比例。
- **工具未完成时沿用同一任务。** 已返回任务 ID 就查询或等待该任务，不重复提交。调用失败、无可用图片或文件损坏时记录失败并报告，不自动重试。
- **检查结果不会自动触发重生成。** 包括留白、风格、错字、遮挡或比例问题；展示现有结果并列出具体待修改项，仍可继续不依赖该问题的制作工作。未通过的图不冒充最终合格海报。
- **用户明确要求修改时才出修订版。** 将累计保留项和本次要改的点写入提示词，持续提供固定字形/材质参考，只对指定比例生成一版，再次检查并展示后停止；其余比例沿用已有文件。用户已明确指定多版或次数时按其要求执行，不自行追加。

可复用提示词（替换花括号内容，执行前填完）：

```text
输入图角色：{固定字形/材质参考}；{当次版式目标，如为修改}；{角色身份参考，如适用}。
持续继承固定参考的圆润字形、白描边、浅暖投影和点缀语言，为「{项目主题}」制作完整中文海报。
累计保留项：{已确定的字号、边距、排字、主体比例等}。此次仅修改：{本轮指定项；首次为完整构图}。
画幅比例 {3:4 / 4:3 / 16:9}，针对这个比例独立构图，背景不透明。
版式：{本比例的标题、主题素材和底标位置；16:9 默认左侧主标题、右侧比例协调的主题素材}。
内容分布饱满，四周保留协调的留白，元素间清晰分隔；字号与主体比例服从内框和间隔。
行宽按自然字形排布，不强制等宽、不拉伸字形、不随意放大小龙填空。
横版内容沿宽度展开，不把竖版构图缩小居中，不在左右留下大块空白黄色竖带。
明亮饱满的亮黄色背景；占主导、厚实圆润的黑色展示字，端头与转角圆钝、字腔舒展，
厚白色贴纸轮廓、浅暖色短投影；少量重点字用橙红色。
文字要像参考图一样饱满灵动，避免方正生硬的普通黑体和厚重硬黑阴影。
准确文案：标题「{标题}」，橙红重点词「{重点词}」，底部标签「{标签}」。
不添加其他文字，不照搬参考图中的产品名和承诺。
主题素材为 {已核实的产品相关素材}；如附小龙母版，保持五官、角、鳞片、
长卷尾和柔和立体材质一致。立体素材带白色贴纸轮廓，与大标题形成完整构图。
底部紫色圆润胶囊标签配白字。少量圆头感叹线和星芒，保持活力与阅读空间。
颜色参考：底色 #FFE600，重点 #FF4B0A，标签 #6200EA，黑白；
角色和真实产品素材保留原生颜色。所有字清楚完整，素材不挡标题。
```

这些色值是生成的视觉目标，不意味着生成像素严格只含这些值。换品牌时同时更新参考图、色板和提示词；模型生成也需要逐次检查，不能保证每张自动一致。

## 可选脚本草稿

仅在需要快速排版草稿，或用户明确选择代码排字时使用：

`python scripts/production.py covers PROJECT/project.json --output-dir OUTPUT`

`project.json.poster` 可配置：

```json
{
  "theme": "yellow-comic",
  "tag": "免费开源 · 本地语音输入",
  "motif": "speech"
}
```

也可使用 `visual: "assets/topic.png"` 提供相对项目的主题图；`visual` 优先于 `motif`。这些配置只控制脚本草稿，不会自动调用图像生成工具。`speech` 只是语音输入主题的说明图，不是产品界面。当前 `production.py render/compile` 附带生成的 `covers/` 也属于这一路线，不能直接当作默认参考风格的最终海报；正式生成图应另存交付目录并记录对应关系。

脚本字体通过 `project.json.font` 或 `VIDEO_FONT_BOLD` 指定；默认探测本机可用字体，字体不随 skill 自动打包。这只影响脚本文字，不影响整张图生成的字形。

生成后检查：三比例文字完整，字形与固定参考一致；内容均衡、四周留白舒适、无明显闲置大洞；标题自然字宽与字号协调；主体比例、白描边、浅投影和少量点缀延续本期要求；缩略图能读出主题；素材不遮挡标题；标签有对比；主题与项目相符。检查后按停止条件结束，不因发现问题自动重生成。生成成功不代表美术已通过验收。

## 开源用户怎样改

- **只换颜色**：编辑 `style.json.poster.palette`，并同步生成提示词，不影响视频色板。
- **换角色**：替换 `style.json.character.file` 指向的透明素材，并检查三比例构图；口型素材另见 [production.md](../tools/production.md)。
- **换主题图／标签**：替换当前项目的生成素材及准确文案；脚本路线才改 `project.json.poster`。
- **换文字风格／布局**：更新本文件的描述、参考图和提示词。若明确使用代码排字，再配置自有字体或修改 `scripts/production_design.py` 的 `poster()`，保留溢出检查和三比例预览。

视频模板、海报模板、声音身份彼此独立。禁止把作者的私人录音、模型、绝对路径、密钥或缓存当作开源默认资源。

## 维护

公共默认风格修改在本文件维护；单期提示词、输出、检查与反馈写入该项目的 `poster-record.md`。改变生成方式、参考图或色板时同步更新本页，避免各处保留冲突默认值。
