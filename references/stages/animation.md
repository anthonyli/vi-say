# 动画、转场与样片

输入是分镜、已设计的画面和最终语义时点；输出是动作与阅读停稳清楚、可逐帧复现的动画及样片。

## 可替换的动画偏好

| 项目 | 默认实现 | 怎样调整 |
|---|---|---|
| 动作时长 | 入场 0.65、强调 0.28、退出 0.22、转场 0.6 秒 | `style.json.motion`；调整后复核动作完成与阅读时间 |
| 转场组合 | `slide/radial/wipe/flip` | `motion.transitionKinds` 选择默认池，场景 `transition` 单独指定 |
| 新转场 | 独立注册表 | `cartoon-transitions.mjs`，详见 [扩展说明](../extensions.md) |
| 角色动作 | 左右站位、镜像与连续迁移 | `characterSide`、`cartoon-motion.mjs` 与绘制组件 |
| 内容动画 | 分步出现、连线、数字增长、状态变化 | 选择对应场景；新行为需实际实现 |
| 复杂对象接续 | Python 共享元素与空间迁移 API | [共享元素工具](../tools/shared-motion.md) |

## 选用现有实现

- 真实录屏上的章节、强调和字幕用 [Remotion 信息层](../tools/remotion.md)。
- 比较、流程、数据与状态解释用 [编辑式场景](../tools/editorial-scenes.md)。
- 同一对象跨场迁移、连续重排与匹配接续用 [共享元素](../tools/shared-motion.md)，其中包含空间和 Python 转场 API。
- 等距装置原理用 [Anatomy SVG](../tools/anatomy-video.md)。
- 用户明确只要简单图片讲义时，可用 [图片时间轴](../tools/timeline.md)；不能把它当作已经完成复杂动画。

按内容选择，不要求每片用全。上述接口并不互通，不能把 Python 转场名称直接放入 Remotion JSON。接入其他渲染工具的条件见 [扩展说明](../extensions.md#接入其他渲染工具)。

## 时间与动作

动作由正在讲的对象和语义触发，使用最终声音的实际词时点。动作本身保持选定实际时长，额外的口播时间用有意义的状态变化或停稳阅读承接，不按下一词间隔拉伸。

先对象、后动作、再反馈，前一步未完成不能交给后一步。共享元素可用 `require_completed` 检查已声明的因果时间，但还要核实实际帧。

相邻场景接续要保留同一对象身份、合理运动方向与遮挡顺序。默认小龙转场保留前场直到后场覆盖完成；Python 翻转有独立几何边界，依其 API 检查。不要为消除静止扫描警告增加无意义漂浮。

产品宣传片先确定相邻镜头的信息关系，再选择转场机制；不预置行业流程或固定镜头顺序。

| 信息关系 | 可复用的动作机制 | 需要从本期分镜取得的输入 |
|---|---|---|
| 多个对象成为整体 | 汇聚、对齐、重排 | 来源对象、目标结构、完成条件 |
| 整体展示细节 | 展开、推近、局部揭示 | 焦点对象、需保留的上下文、阅读尺度 |
| 同一对象进入新场景 | 匹配迁移、缩放、容器接续 | 对象身份、起止位置、遮挡顺序 |
| 操作产生新状态 | 状态替换、结果逐步显现 | 前态、实际动作、反馈、后态 |
| 切换不同解释对象 | 明确切镜或遮罩过渡 | 切换原因、新焦点、视觉方向 |

对象名称、品牌、业务步骤、接点与时长写入项目分镜。以上是设计方法，不是渲染器已支持的效果名称；按所选实现接入，核对前态、中间态、后态及原速播放。主动作完成后留出阅读时间，音效服从实际接点，不改变旁白速度凑节拍。

## 小龙与 Bot 的动作编排

Bot 的几何轮廓、颜色、眼睛、材质和变形边界独立维护在 [Bot 样式](../styles/bots.md)。本模块只安排动作与语义；同一套任务身份和动作可换用另一套已实现的造型。

上述选择已接入 [动画模块接口](../tools/animation-modules.md)：Bot 动作用 `bot` 的 `action/actions/keyframes`，汇聚与派发用 `flow`，连接用 `connection`，内容传递用 `route`，指针用 `pointer`，截图聚焦用 `focus`。先选择已有模块并填写本期数据；确有缺口时才按 [扩展说明](../extensions.md) 新增实现。

| 动作 | 应表达的行为 | 检查点 |
|---|---|---|
| 探头、转眼 | 注意到新任务或当前操作 | 看向实际对象，避开关键文字 |
| 弹跳 | 接到任务或完成一步 | 蓄力 → 起跳拉伸 → 落地压扁 → 回弹，阴影同步 |
| 轻碰、挤压 | 配角间的调皮互动 | 有接近、接触、形变与分开，标签保持可读 |
| 工作、庆祝 | 指令已送达或结果已完成 | 由当前结果状态触发，完成后回到可阅读状态 |
| 汇合、归队 | 多份结果汇总或任务重新派发 | 同一对象从来源走到明确落点，保留身份 |

跳跃高度、形变和相位错开，避免所有 Bot 按同一节拍蹦跳。配角动作围绕当前解释安排，机器人热闹程度不能代替信息变化；连续跳舞或仅左右摇摆不算完成操作动画。

小龙使用中心开场、景别变化、参与操作与连续跨场迁移；只移动或缩放同一姿态时如实描述，不冒充新骨骼动作。保持嘴部跟随最终音轨，身体运动不改变口型坐标。

操作段先写“对象前态 → 动作 → 可见反馈 → 后态”，再按信息关系选择汇聚、分流、迁移、更新或揭示。明确原对象、接收位置和完成条件，用当前声音实际讲到动作或结果的时点触发；动作逐个完成并留出阅读时间，不按整段时长均摊。具体对象、流程和触发词留在项目分镜中。

## 样片与调整

先渲能暴露主要难点的连续片段，包含完整状态变化和需要验证的接点。看起始、中间、完成帧，并原速播放；有声音时另查语义与听感。默认先做静态检查再做连续预览，无声样片明确标记。

针对不满意的模块局部修改；新增效果先在本期副本验证，可复用后再进入公共注册表或组件。保留原版，复查受影响接点；样片通过后扩展全片。检查记录和最终交付见 [delivery.md](delivery.md)。
