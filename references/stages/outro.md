# 互动片尾

输入是本期结尾与当前音色；输出是与完整音轨一致的收尾画面、口播和动作时点。

## 可替换的片尾偏好

默认内容唯一来源为 `assets/production/outro.json`：标题、副标题、旁白，以及留言→关注→点赞三项的文字、详情、图标和语义锚点。可在这里改成自己的系列口吻；不要求所有使用者保留默认原句。

默认在正文后收尾，片尾之后不追加新内容。用户明确不要片尾时，项目设置 `omit_outro: true`。每期片尾使用本期音色，不能把旧音色片段硬接到新声音上。

## 编排与实现

1. 在完整脚本中加入本期片尾口播，再生成或整理最终音轨。
2. 取得当前音轨的真实词起点。`production.outro_scene(start, end, anchors)` 接受 `outro.json.items[].anchor` 对应的绝对秒数，转换为场内 `items[].at`。
3. 默认最后场景为 `cta`，带 `outroId: "community-outro-v1"`，项目末尾覆盖实际声音终点。初始项目的秒数只是无声布局示例。
4. 文本与 `outro.json` 中的项目顺序保持一致，动作有完成与停稳时间；检查器不会自动识别词时间是否正确。

目前 `cta` 支持两到三项，内置 `comment/follow/like` 图标。改成其他行动可先改文字；新图标或布局需改 `src/cartoon.jsx`，项目数量、类型或 ID 变化时同时更新 `cartoon-contract.mjs` 和相关测试。`production.py` 按该 JSON 创建初始片尾与检查末场，不能仅改一个未实现的图标名。

## 复核

核对片尾话语、实际声音、字幕和画面动作一致，用户要求的系列收尾仍位于最后。动画是互动示意，不冒充平台已完成点赞或关注。发布文案的互动问题见 [publishing-copy.md](publishing-copy.md)，可随主题写，不机械复制视频片尾全文。
