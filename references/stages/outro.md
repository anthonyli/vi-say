# 互动片尾

输入是本期结尾与当前音色；输出是与完整音轨一致的收尾画面、口播和动作时点。

## 可替换的片尾偏好

默认内容唯一来源为 `assets/production/outro.json`：收束句（默认“今天分享就到这里。”）、标题、副标题、旁白，以及留言→关注→点赞三项的文字、详情、图标和语义锚点。`init` 生成的口播稿已按“收束句 + 片尾旁白”写好。可在这里改成自己的系列口吻；不要求所有使用者保留默认原句。

默认在正文后收尾，片尾之后不追加新内容。用户明确不要片尾时，项目设置 `omit_outro: true`。每期片尾使用本期音色，不能把旧音色片段硬接到新声音上。

## 编排与实现

1. 在完整脚本中加入本期片尾口播，再生成或整理最终音轨。
2. 取得当前音轨的真实词起点。`production.outro_scene(start, end, anchors)` 接受 `outro.json.items[].anchor` 对应的绝对秒数，转换为场内 `items[].at`。
3. 默认最后场景为 `cta`，带 `outroId: "community-outro-v1"`，项目末尾覆盖实际声音终点。初始项目的秒数只是无声布局示例。
4. 文本与 `outro.json` 中的项目顺序保持一致，动作有完成与停稳时间；检查器不会自动识别词时间是否正确。

comic 主题和录屏路线的片尾共用 [comic-outro.jsx](../../assets/remotion/src/comic-outro.jsx)：三块积木分别落在“留言/关注/点赞”的实测词时间上，最后淡出到墨蓝。改版式只改这个组件；项目数量、类型或 ID 变化时同时更新 `cartoon-contract.mjs` 和相关测试。渲染前检查会核对片尾场景的字幕确实讲到了这三个词。

沿用本系列且用户未省略时，三项都属于片尾范围；“评论区聊聊”或“转发给朋友”不能代替另两项。题材只改变主题措辞，非工具科普不照搬“更多好工具”。其他品牌与原声剪辑按其任务范围，不强加三连。发布稿里写了三项不等于视频里已有，交付前实查最终片尾。

## 复核

真人原声录屏的积木片尾走[原声录屏导出](../tools/recorded-video.md#双语成片与有声片尾)。先在录屏段说完收束句，再入场。既有 CTA 顺序直接取模板，结合实际词时间驱动积木，片尾跟正文补录使用同一获授权的本段口播参考。

核对片尾话语、实际声音、字幕和画面动作一致，用户要求的系列收尾仍位于最后。动画是互动示意，不冒充平台已完成点赞或关注。发布文案的互动问题见 [publishing-copy.md](publishing-copy.md)，可随主题写，不机械复制视频片尾全文。
