# 画面、图解与视觉风格

输入是分镜、真实素材和最终语义时点；输出是能解释当前论点的画面与状态。动作安排见 [动画](animation.md)，具体参数见对应 [工具接口](../workflow.md#工具接口)。

## 可替换的视觉偏好

| 项目 | 随包示例与其他选择 | 修改位置 |
|---|---|---|
| 角色 | 默认小龙；可换角色或采用纯操作、纯图解 | [角色](../styles/character.md) |
| 颜色 | 默认五色加黑白；可换品牌色 | [色板](../styles/colors.md) |
| 信息形态 | 大主体、比较、流程、图表、真实界面、纸感拼贴 | 当前分镜与对应绘制实现 |
| 字体、材质、留白 | 随当前品牌与受众选择 | 本地字体、渲染组件或场景适配器 |
| 字幕 | 按任务选择烧录、独立文件或不显示 | [字幕](captions.md) |

偏好描述用于指导设计，不代表渲染器已有同名配置。海报与视频色板独立；当次品牌、参考和已认可素材优先。

沿用当前小龙系列时采用 [明亮玻璃科技风](../styles/glass.md)，配角外观按独立的 [Bot 样式](../styles/bots.md) 选择；小龙、Bot、背景与操作内容可以分别调整。字幕去标点与关键词高亮由 [字幕模块](captions.md#中文口播的显示标点与关键词) 管理，动作由 [动画模块](animation.md#小龙与-bot-的动作编排) 管理。

## 按解释任务选择图解

| 要解释什么 | 应看见什么 | 当前可用路线 |
|---|---|---|
| 概念或主结论 | 一个足够大的具体主体，随后补必要限定 | 小龙 `hero`、编辑式 `hero`、自定义图形 |
| 步骤与操作 | 对象、动作、反馈和结果 | 小龙 `steps/demo`、真实录屏、编辑式 `demo` |
| 前后／方案比较 | 相同条件下可核对的差异 | 编辑式 `compare`、信息层 `comparison` |
| 因果、结构、工作流 | 输入、节点、作用方向与结果 | 编辑式 `flow`，含分支 `levels` |
| 数量与趋势 | 来源、单位、共同尺度和正确几何比例 | 编辑式 `bars`；更复杂图表需扩展 |
| 条件、分类与整理 | 清楚的分组依据和具体条目 | 报告、台账、笔记本、索引等 Pillow 布局 |
| 机制与空间关系 | 同一对象的状态变化、迁移或装置因果 | 共享元素、Anatomy SVG |

流程图不能只是旁白拆成方框；节点和连线要表达真实关系。图表保留口径与来源，不用装饰百分比。说到“修改、拖动、切换、计算”时，画面应呈现对应对象和结果；示意界面不能冒充产品实测。

## 真实产品截图

GitHub 项目介绍有产品界面素材时，实际采集并在成片中展示。优先截图官网、在线演示或产品界面，也可使用官方现成的产品截图；为对应功能至少安排一个真实产品画面，避免整片只有角色、标题和功能卡片。

按正在解释的内容调整浏览器窗口、滚动位置与截图区域，让关键界面足够大、文字可读。保留图中真实状态，说明素材来源，不把官方演示画面说成本人实测。仓库主页可辅助展示项目和 Star 数，不能替代产品界面；生成的示意界面也不能充当真实截图。

## 组织画面与复用参考

产品宣传片的素材先分清：实际界面／录屏、官网人物与品牌素材、功能示意图。检查用户 HTML 引用的图片、SVG 和背景资源，不只提取正文，也不把官网功能插图当作实际系统截图。缺少实际界面时，可在用户已授权的范围内制作并明确标识演示界面；原有人物与品牌素材按叙事需要使用，避免另找无关商务素材。

浅色产品片不等于平铺白底。可用低饱和品牌光场、弧面、前后景和一致光向的投影建立空间，让界面仍是主焦点。品牌色负责识别，不同类别的对象可用少量辅助色区分，同时配合图标／标签；不强制整片单色，也不把装饰颜色冒充风险等级。具体品牌、人物和空间样式留在当期，不写成通用固定皮肤。

先看参考的代表性连续片段，提炼主体、阅读顺序、材质、留白和状态变化。复用方法，不复制其品牌、数字、旁白和固定章节。参考中的来源栏、页码或纸纹可按需要采用，不是全片必须项。

每一刻保留明确主焦点。标题讲结论、主体解释关系、字幕辅助跟读，避免三处重复全文。截图太密时聚焦当前操作，重要内容不缩成不可读的小窗。

纸张、便签、胶带、圈注与箭头可用于分类和推导；纹理和倾斜不影响正文阅读。阴影、透视和材质保持一致；不要求所有论点套同一种圆角卡片。

先渲关键静态状态，再加入运动。按 hierarchy、composition、material_consistency、legibility、content_fit 检查信息层级、构图、材质、可读性和内容适配。目标为带平台白色按钮的版本时，对实际比例单独检查右侧与底部对比，不把平台版本限制变成所有视频的统一背景要求。

## 实现与复核

小龙／编辑式完整场景当前为 16:9；`overlays` 保留 16:9、4:3、3:4 接口。Pillow 六类布局固定 1920×1080，Anatomy 要编写确定性的 SVG 场景。需要新形态时按 [扩展说明](../extensions.md) 同时实现画面、参数校验、素材映射与预览点。

只改风格名称或新增 JSON 字段不等于实现。实际关键帧记录在本期 `visual-plan` 或分镜中，正式检查见 [交付](delivery.md)。编辑式模板的微漂浮和回弹是该模板默认值，不是所有视频的要求，也不能代替语义变化。
